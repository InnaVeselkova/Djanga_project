# Интернет-магазин

## Описание проекта

Этот проект представляет собой веб-интернет-магазин, предназначенный для просмотра товаров и оставления отзывов. Пользователи могут просматривать ассортимент товаров, получать подробную информацию о каждом продукте, а зарегистрированные пользователи — оставлять отзывы

## Установка

Для установки проекта:
1. Клонируйте репозиторий: 
git clone https://github.com/InnaVeselkova/Djanga_project
2. Активируйте виртуальное окружение:
python -m venv venv
source venv/bin/activate   # для Linux/MacOS
venv\Scripts\activate    # для Windows
3. Установите необходимые зависимости:
pip install -r requirements.txt

## Использование

Данный проект — это интернет-магазин, разработанный с использованием Django, с тремя приложениями:

catalog — управление товарами и категориями

blog — блоговые записи 

users — управление пользователями

Основные возможности и контроллеры 

Главная страница (HomeListView) — отображает список всех товаров. 

Страница контактов (ContactsView, contacts_form) — форма для отправки сообщений. 

Подробное описание товара (ProductDetailView) — доступно только зарегистрированным пользователям.

Добавление товара (ProductCreateView) — для авторизованных пользователей.

Редактирование товара (ProductUpdateView) — доступно владельцам товара или пользователям в группе "Модератор продуктов".

Удаление товара (ProductDeleteView) — те же права, что и у редактирования.

Публикация и снятие с публикации — через UnpublishProductView.

Удаление товара (DeleteProductView) — для авторизованных пользователей с соответствующими правами.

Доступ к страницам с управлением товарами (создание, редактирование, удаление) ограничен по правам пользователя.
Для выполнения определённых действий требуется наличие специальных разрешений (PermissionRequiredMixin), например, право catalog.can_unpublish_product.
